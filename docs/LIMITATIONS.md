# Limitations

This is source construction accepted under Dirty Mode. No install, type/lint/test/build, browser, Deno, database, evaluation or provider execution has validated it. Written contract tests inspect source structure; they do not prove deployed RLS, concurrency, isolation or transaction behavior. See DEFERRED-VALIDATION.md before activation.

- **Integrity aid, not tamper-proof evaluation.** Owners originally supply labels and can retain them. The lock deters casual extra looks; it cannot prevent external scoring, admin database changes or advance knowledge. MemoryStore is page memory, and reload clears its history.
- **Content lineage has limits.** Reordered/renamed identical content shares a scope; changed content creates a fresh scope with informational parent lineage. Arbitrary edited descendants cannot inherit all contamination reliably without a separate identity policy. Every looked scope must be burned before re-splitting that same content.
- **Delimiters are not injection immunity.** Random nonces prevent simple delimiter collisions. They do not make a model ignore hostile instructions. Probe results are exploratory, and state-filtering does not establish model safety.
- **Pair equivalence is necessary, not sufficient.** Substring/fact/whitespace-length checks reject obvious bad pairs. Passing does not prove semantic equivalence; a human must assess the separately written answers. Whitespace words are not billable model tokens.
- **Small sets have limited precision.** Wide intervals and `cannot support` are useful outcomes. Interval half-width describes observed precision, not a power analysis or guaranteed minimum detectable effect.
- **Bootstrap assumptions matter.** Whole split groups are resampled; inference assumes those groups are exchangeable. Correlation across groups, dataset selection and annotator selection can invalidate coverage. Undefined draws are counted; too many make the interval undefined.
- **Human agreement is a reference.** Equal-weight pair means depend on overlap floors and which pairs are defined. It is not a theoretical ceiling. Consensus ties are excluded only from consensus metrics; per-annotator agreement remains separate.
- **Public data may be memorized.** Public benchmark agreement does not establish unseen-task quality. Synthetic annotators and planted defects test plumbing, not model ability. The marker-based merge repair is deliberately mechanical.
- **Costs require activation evidence.** A token bound based on prompt bytes assumes at least one byte per billed token and adequate framing coverage. Unexpected provider framing or usage can exceed an estimate. Claims reserve against the dated price book; actual settlement records usage rather than hiding an overrun. Saved run plans remain estimates when price entries change.
- **Ambiguous calls are not free.** A timeout, missing usage or interrupted sent call can have incurred charges. Reservations remain until explicit owner resolution. Reconciliation and failure scenarios must be exercised against a real isolated backend.
- **Live cache reuse is absent.** Cache rows are written but not read during live execution. Repeated new dev runs still incur provider calls. Held-out version reuse is separately enforced by the lock. Local report display caching is not a durable materialized report.
- **Only browser-driven work exists.** There is no background worker, scheduler, Docker stack or CI/deployment infrastructure. Closing the page stops further chunk requests. Reload requires selecting/recomputing durable live evidence.
- **Provider contracts are provisional until checked.** Jev, Anthropic and compatible endpoint schemas, usage/model fields, timeouts, auth gateways and platform secret names need live verification. Missing configuration refuses; no synthetic answer substitutes for a failed live call.
- **Policy thresholds are proposals.** Bands, missingness floor, overlap floor, two-look rule, bootstrap settings, Jev margin, cap and chunk timings are pinned for reproducibility, not established optimal choices. Changing a policy requires a new version and honest provenance.

Not included: pairwise judging, juries, self-preference probes, model-written rubric text, automatic edits, annotation UI, fine-tuning, teams, generic task types, ECE/Brier calibration or a phase-two MT-Bench adapter. All four planned dev probes and the PAV comparator are present as source; no declared feature cut was taken.
